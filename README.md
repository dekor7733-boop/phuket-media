# Медиа для «Спроси Кая»

Публичное хранилище картинок и роликов для автопубликации в Instagram.

Файлы здесь доступны всем по прямой ссылке — так требует Instagram Graph API:
серверы Meta скачивают медиа по HTTPS-адресу перед публикацией.

**Сюда нельзя класть:** ключи, токены, базы данных, персональные данные,
материалы клиентов и любые файлы, не предназначенные для публикации.
